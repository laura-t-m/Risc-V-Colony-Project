# Risc-V-Colony-Project
CSCI-80 (Introduction to Computer Systems) - Risc-V Colony: A Cellular Automaton Project

Program will model a colony of cells on a two-dimensional board. During each generation, cells are born, survive, or die according to the number of living cells surrounding them.

Complete program should:
• Allow user to create or select a colony.
• Display its development over multiple generations.
• Calculate an integer score based on how successfully the colony survives.

(Project shall use only integer and character operations - No floating-point instructions)
